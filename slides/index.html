✦ Auto Invitation + Logging

Invitation auto-sent to any influencer added to campaign. System logs: which number & which office sent it.

  • Trigger: Influencer added to campaign
  • Log: Phone number ID + Office source

⚠ Missing Gap — Brief Sending

Currently only Invitation & Reminder exist in WA Pro. Brief Sending is missing — must be added.

② Smart Reminders

Reminder auto-trigger for Pending only — after excluding No Response / Paid / Rejected. Two stages:

Reminder 1→Reminder 2=Based on Target %

If target has shortage → trigger reminder to Confirmed influencers to complete target.

الدعوة التلقائية مع التسجيل ✦

الدعوة تُرسل بشكل أوتوماتيك لأي إنفلونسر في الحملة، ويتم تسجيل الدعوة اتبعتت من أنهي رقم أو أنهي مكتب.

إضافة إنفلونسر←دعوة أوتوماتيك←تسجيل المصدر

⚡ Edit Logic

AUTO by default+Manual Override for exception

If a module fails to update sheet, Operation Agent can directly edit status / add info in Confirmation Sheet.

↻ Periodic Backup to Dropbox

Backend job exports all sheets periodically to Dropbox Shared Folder.

☁
Dropbox Locally on ServerOpen on Dashboard Server, periodic export
  • Export runs on schedule (e.g., every 15 min)
  • Shared folder accessible to Ops

🛟 Fallback Plan

If Confirmation Sheet on system down / disconnected office / any issue → resume work via Dropbox Share temporarily until fix.

منطق التعديل ⚡

يكون التعديل في الشيت ده الأساسي Automatic. ويقبل Manual في حالات خاصة لو حصل مشكلة في Module.

  • Operation Agent يقدر يعدل Status أو يضيف معلومات مباشر
  • تعديل مباشر في شيت Confirmation

النسخ الاحتياطي الدوري

بيحصل في الـ Back-end Periodic Backup لكل الشيتات دي في Dropbox Shared Folder. Dropbox مفتوح Locally على Server خاص بالـ Dashboard Server وبيتم Export بشكل Periodic.

خطة الطوارئ 🛟

بحيث لو حصل مشكلة في Confirmation Sheet على السيستم، أو كله حصل له Down أو disconnected office، نقدر نرجع للشيتات دي عن طريق Dropbox Share ونشتغل عليها بشكل مؤقت.
